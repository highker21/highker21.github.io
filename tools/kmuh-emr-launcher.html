高醫電子病歷快速跳轉（Chrome 插件）

選院區、輸入病歷號，直接開啟該病人的電子病歷，不用一層層點選單。快捷鍵 Alt+E 叫出輸入框。

下載

插件 v1.1.1（zip）

只在院內網路可用。沿用你在 Chrome 已登入的院內帳號，插件不處理帳號密碼；病歷號不儲存，只記住院區與職編。

安裝（第一次）

  1. 下載 zip，解壓縮到一個固定的資料夾（之後不要搬動或刪除）。Windows 用「解壓縮全部」時會多包一層，請選到裡面有 manifest.json 的那一層。
  2. Chrome 網址列輸入 chrome://extensions，打開右上角「開發人員模式」。
  3. 按「載入未封裝項目」，選剛才的資料夾。
  4. 點右上角拼圖圖示，把「高醫電子病歷快速跳轉」釘選到工具列。第一次使用請在「設定：職編」填入職編。

更新到新版

  1. 新版解壓後，直接覆蓋原本的資料夾。
  2. 到 chrome://extensions，在這個插件上按「重新載入」↻。

使用

  1. 點插件圖示（或按 Alt+E），選院區，輸入病歷號，按 Enter。
  2. 1～7 碼的純數字病歷號會自動補 0 成 8 碼。
  3. 還沒登入時，插件會在背景開登入頁；登入後再查一次即可。
注意
  • 支援院區：高醫、岡山、小港、旗津。
  • Windows 版 Chrome 的 Alt+E 可能和瀏覽器選單衝突；按了沒反應時，到 chrome://extensions/shortcuts 改成別的組合（例如 Alt+Shift+E）。
