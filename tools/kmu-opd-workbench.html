KMU Note 門診工作台（Chrome 插件）

在 KMU Note 門診頁右邊開一個側邊欄，一個畫面看完今天門診每位病人的上次 SOAP、目前用藥、最近一次抽血、眼底與甲狀腺檢查、本季疫苗。院內網路使用。

下載

插件 v0.4.6（zip）

只讀病歷、不連院外。權限只有「暫存」一項（讀過的結果放在瀏覽器記憶體，關掉瀏覽器就清空）。

安裝（第一次）

  1. 下載 zip，解壓縮到一個固定的資料夾（之後不要搬動或刪除）。要選到裡面有 manifest.json 的那一層（extension 資料夾）。
  2. Chrome 網址列輸入 chrome://extensions，打開右上角「開發人員模式」。
  3. 按「載入未封裝項目」，選剛才的 extension 資料夾。

更新到新版

  1. 新版解壓後，直接覆蓋原本的資料夾。
  2. 到 chrome://extensions，在這個插件上按「重新載入」↻，再重新整理門診頁。

使用

  1. 開 KMU Note 門診頁，選好日期、科別、午別後按查詢。
  2. 按右上角「門診工作台」，右邊出現側邊欄（原本的門診頁會往左讓位）；按「讀取未讀的」一位一位讀。
  3. 在左邊清單點某位病人，側邊欄會捲到他的卡片。讀過的會記住，再按只讀新的；要更新按「全部重讀」或卡片上的「重讀」。
  4. 每張卡片：
    • 上次門診 SOAP（自己寫的優先，沒有就本科；都沒有顯示「本科初診」），分 S、A&P 兩欄。
    • 目前用藥（含雲端藥歷），預設只列藥名，展開看用法、到期、來源。
    • 最近一次抽血：重點項目、異常項目；eGFR（CKD-EPI 2021 與 MDRD）、UACR 院內沒報時由插件計算並標「外掛計算」；甲狀腺病人補 TSH、free T4，甲癌加 Tg。
    • 眼底攝影（一年內）、甲狀腺超音波與細胞學（日期與結果分類）。
    • 本季流感、新冠疫苗，沒打的有底色。
  5. 「儲存 CSV」可以把整張表存成 Excel 打得開的檔案。
注意
  • 每讀一位病人，院內就會留下一筆病歷查閱紀錄，和你自己點開那位病人一樣。
  • 病歷是在背景的獨立讀取框裡開，不會切換你自己開著的病歷頁上的「目前病人」；每一頁都核對病歷號，對不上就不顯示。
  • 「自動延長」預設勾選：院內倒數剩 29 分鐘時替你按原本的「延長時間」鈕。院內閒置鎖定是資通安全規定，離開座位前請登出或取消勾選。畫面鎖定時側邊欄會整個隱藏。
  • CSV 檔含病人資料，請勿放進雲端資料夾，用完請刪除。
  • 插件計算的 eGFR、UACR 僅供參考，請以院內報告為準。
