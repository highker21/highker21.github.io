🅿️ 附近停車查詢

按「查詢附近停車」開始

          設定

          還沒有金鑰？到 TDX 官網免費申請：右上角「註冊」→ Email 驗證 → 等審核 → 登入後到「會員中心 → 資料服務 → API 金鑰」複製 Client ID 與 Client Secret，貼到上面。

          金鑰只存在這台裝置的這個瀏覽器，不會上傳到我們的伺服器；只會直接送到 TDX 換取通行證。iPhone「加到主畫面」後是另一個獨立空間，要再輸入一次。新北、新竹不填金鑰也能查。

          使用說明

          1. 按「查詢附近停車」，允許定位，地圖與清單會列出附近停車場和路邊停車格。

          2. 點停車場可一鍵用 Google 或 Apple 地圖導航。

          3. 停車：新北、新竹不用金鑰；其他縣市、YouBike、路況要 TDX 金鑰——到 TDX 官網免費申請，再填到「設定」。

          4. iPhone 可用 Safari「分享 → 加入主畫面」當 App 用；加到主畫面後金鑰要重新輸入一次。

          定位只在你的手機上計算距離，不會送到我們的轉送伺服器；地圖圖資與縣市判斷由 OpenStreetMap 提供，會看到你所在的大致範圍。觀光分頁有三種方式（在「設定」切換）：① 預設只送出你所在約 11 公里格子的範圍；② 縣市模式只送出縣市名稱（依定位判斷或自選）；③ 全國資料完全不送位置。觀光照片放在各縣市網站，按「看圖」才會載入（那時對方會看到你的 IP）。
          資料：交通部 TDX、新北市政府、新竹市政府開放資料，依政府資料開放授權條款第 1 版使用；合併與篩選不代表機關背書。
