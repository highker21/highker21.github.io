中文檢驗報告（Chrome 插件）

體系病歷「檢驗」頁多三個鈕：把英文檢驗報告整理成中文說明版、把多個項目一年內的變化畫成折線圖，或開「🧮 計算機」自動帶入檢驗值算臨床指標，預覽後印給病人。院內網路使用。

下載

插件 v0.5.1（zip）

只讀病歷、不連院外、不存檔；不需要任何額外權限。

安裝（第一次）

  1. 下載 zip，解壓縮到一個固定的資料夾（之後不要搬動或刪除），會得到 kmu-lab-zh 資料夾（裡面有 manifest.json）。
  2. Chrome 網址列輸入 chrome://extensions，打開右上角「開發人員模式」。
  3. 按「載入未封裝項目」，選 kmu-lab-zh 資料夾。
  4. 已經開著的檢驗頁請重新整理一次。

使用

  1. 開體系病歷的「檢驗」頁，院內「列印」鈕旁邊會多出「🖨 中文版」「📈 多項變化」。
  2. 🖨 中文版：左邊點抽血日期，直接按就是當天全部；只要其中幾份就先勾選再按。
  3. 📈 多項變化：列出查詢區間內驗過的項目，勾一個或多個，每項一張折線圖加數值表。要看一年請先把「查詢區間」改成 1 年。
  4. 先出現預覽，確認後按「🖨 列印」；按「關閉」或 Esc 就清掉。

報告內容

  • 抬頭：姓名、病歷號、院區、採檢日、報告日（不印身分證、生日）。
  • 依類別分區，每項：中文名（英文原名）、結果、單位、參考範圍、一句「這項在看什麼」。
  • 高低照院內報告的標示（↑偏高、↓偏低、＊異常、危急值），插件不自己重算。
  • eGFR、UACR：院內報告沒有時，插件自己算並標「外掛計算」——eGFR 用 CKD-EPI 2021 與 MDRD（同院內 GFR 圖），年齡算到抽血當天，附 G1–G5 分期；UACR 用同一份尿液的白蛋白÷肌酸酐，附 A1–A3 分級，沒寫單位就不算。性別由頁面身分證第 2 碼判斷，只在記憶體使用、不印出。「多項變化」也能勾這兩項。
  • FIB-4、HOMA-IR：院內沒報時外掛計算。FIB-4＝年齡×AST÷（血小板×√ALT），放肝功能，附低／不確定／高風險判讀（65 歲以上低切點 2.0）；HOMA-IR＝空腹血糖×空腹胰島素÷405，放血糖，僅適用空腹、未使用胰島素者，2.5 為參考切點。都要同一天、各剛好一筆、單位認得才算。
  • 沒有中文對照的項目保留英文，標「無中文對照」。
  • 頁尾：「非官方中文報告，翻譯僅供參考」。
注意
  • 體系多院區一起查詢時，中文版會把當天各院區的報告整合成一份（每項標院區）；多項變化把各院區同一項目畫在同一張圖（不同形狀的點＋圖例），單位不同就分開畫。
  • 院內其他院區報告的勾選框是灰的；插件印的是中文說明版、非正式報告，沒勾時會一併納入，有勾時只印勾的那幾份。
  • 讀不到病歷號或姓名、或報告清單和這一頁的病人對不上時，不會產生報告（避免印錯人）。
  • 印出的報告含病人資料，若另存 PDF 請勿放進雲端資料夾，用完請刪除。
版本紀錄
  • v0.5.1（2026-11-25）：計算機改成浮動小視窗（不蓋住整頁、可拖曳、可拉大小、可縮小，位置會記住）；自動帶入身高、體重（讀同一位病人 TPR 頁最近一次，各標日期，超過一年提醒；病歷號對不上就留空請手填）。
  • v0.5.0（2026-11-24）：新增「🧮 計算機」鈕，浮動視窗開檢驗資料臨床計算機，自動帶入這位病人最近的檢驗值、年齡、性別並算好（mmol/L 自動換算 mg/dL；混到不同日期的數值會標示提醒），可複製、列印。
  • v0.4.1（2026-11-24）：修正院內尿肌酸酐（U-CRE）、岡山血清肌酸酐（CRTN）認不得，UACR、eGFR 之前常算不出來；一年折線圖改成 eGFR、UACR、UPCR、HbA1c、空腹血糖各自勾選。
  • v0.4.0（2026-11-24）：預設算 eGFR、UACR、UPCR（新增）、FIB-4、HOMA-IR，缺資料的那項不顯示；中文版預覽可勾「附一年 eGFR／UACR 折線圖」，會記住設定。
  • v0.3.3（2026-11-24）：修正「📈 多項變化」異常值沒畫進圖、表格露出「flag=」；表格改標 ↑偏高／↓偏低。異常的肌酸酐、血糖也算進 eGFR、HOMA-IR 變化。
  • v0.3.1（2026-11-23）：加上 FIB-4、HOMA-IR（院內沒報時外掛計算並標示），多項變化也可勾。
  • v0.3.0（2026-11-23）：中文版與多項變化加上 eGFR（CKD-EPI 2021、MDRD）與 UACR，院內沒報時外掛計算並標示。
  • v0.2.0（2026-11-23）：體系多院區一起查詢時，中文版與多項變化都納入各院區。
  • v0.1.1（2026-11-23）：多項變化只用本院區報告；報告與頁面病人核對；單獨「-」不翻成陰性；危急值只認明確標示；單位與參考範圍往前補。
  • v0.1.0（2026-11-23）：🖨 中文版（當天全部或勾選）、📈 多項變化（折線圖）、中英對照 185 項。
