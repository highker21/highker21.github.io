高醫甲狀腺細胞學批次查詢（Chrome 插件）

貼上一串病歷號，逐一取得甲狀腺與頸部淋巴結細胞學的全部報告（新到舊），整理成一張表，可下載 CSV。依診斷整列上底色（benign、nondiagnostic、atypia、suspicious、malignant 各一色）。

下載

插件 v1.4.0（zip）

只在院內網路可用（高醫、岡山）。沿用你在 Chrome 已登入的院內連線，插件不處理帳號密碼；病歷號與報告只留在查詢頁，關掉分頁就清除，只記住院區與職編。

安裝（第一次）

  1. 下載 zip，解壓縮到一個固定的資料夾（之後不要搬動或刪除）。Windows 用「解壓縮全部」時會多包一層，請選到裡面有 manifest.json 的那一層。
  2. Chrome 網址列輸入 chrome://extensions，打開右上角「開發人員模式」。
  3. 按「載入未封裝項目」，選剛才的資料夾。
  4. 點右上角拼圖圖示，把「高醫甲狀腺細胞學批次查詢」（紫底「甲」字圖示）釘選到工具列。

更新到新版

  1. 新版解壓後，直接覆蓋原本的資料夾。
  2. 到 chrome://extensions，在這個插件上按「重新載入」↻。

使用

  1. 先在 Chrome 打開一次院內系統，確認已登入。
  2. 點插件圖示，會開出查詢頁。選院區，第一次使用要填職編。
  3. 貼上病歷號（一行一個，或用空白、逗號分隔），按「開始查詢」。
  4. 查完按「下載 CSV」。同一位病人每一份甲狀腺、淋巴結報告各列一列，新到舊；「筆數」欄的 1/3 表示該部位共 3 份中的第 1 份（最新）。

分級上色（看 Diagnosis 欄；nondiagnostic 另看檢體適當性）

benignBenign／Bethesda II／Negative for malignancy／goiter、thyroiditis、colloid、adenomatous nodule、reactive、lymphadenitis、hyperplasia
nondiagnosticNondiagnostic／Unsatisfactory／Insufficient／Inadequate／Cyst fluid only／Bethesda I
atypiaAtypia of undetermined significance／AUS／FLUS／Bethesda III／atypical cells
suspiciousSuspicious for malignancy，以及 cannot rule out／cannot be excluded 這類無法排除的寫法
malignantMalignant、carcinoma、cancer、metastatic、lymphoma、Bethesda VI（已排除「Negative for…」這類否定句）

判斷順序：suspicious → malignant → atypia → nondiagnostic → benign，先命中者為準（例如 reactive atypia 算 atypia）。Follicular neoplasm／Suspicious for a follicular（Hürthle、oncocytic）neoplasm（Bethesda IV）不上色。上色只是提示，不能取代逐份閱讀報告。

注意
  • 每查一位，插件會在背景開一個病歷分頁、讀完報告自動關掉，請不要去點它；查詢期間也不要在同一個 Chrome 另開別的病人病歷。
  • 防串號：報告與頁面上的病歷號都要對得上查詢號碼；對不上會標「查詢失敗：與查詢不符」且不輸出報告。標「請抽查」的，請對照電子病歷確認。
  • 查詢中途關掉查詢頁，可能留下沒關掉的病歷分頁，請手動關掉。
