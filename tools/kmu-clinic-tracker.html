高醫門診進度記錄（Chrome 插件）

選高醫體系（岡山、附院、小港）的醫師或診間，定時記錄每一號的報到、開始看診與結束時間，並輸出統計報表（可列印成 PDF、下載 CSV）。可以預約時間，到時自動開始記錄。

下載

插件 v1.2.1（zip） 安裝教學（PDF）

只記錄看診號碼與狀態，不記錄病患姓名（醫院網站也沒有提供姓名）；資料只存在你自己的 Chrome 裡，不上傳。

安裝（第一次）

  1. 下載 zip，解壓縮到一個固定的資料夾（之後不要搬動或刪除）。Windows 用「解壓縮全部」時會多包一層，請選到裡面有 manifest.json 的那一層。
  2. Chrome 網址列輸入 chrome://extensions，打開右上角「開發人員模式」。
  3. 按「載入未封裝項目」，選剛才的資料夾。
  4. 點右上角拼圖圖示，把「高醫門診進度記錄」釘選到工具列。

更新到新版

  1. 新版解壓後，直接覆蓋原本的資料夾。
  2. 到 chrome://extensions，在這個插件上按「重新載入」↻。舊的記錄會保留。
注意
  • 不要按「移除」來更新：移除插件會把所有記錄一起刪掉。
  • 記錄期間 Chrome 要開著、電腦不能睡；插件視窗可以關掉。
  • 預約開始：時間到時 Chrome 要開著、電腦醒著。錯過的話，醒來時還沒到收工時間仍會補開；已過收工時間就標「已錯過」。

使用

  1. 點插件圖示，選院區和午別，按「載入診間」，勾選醫師或診間，按「開始記錄」。
  2. 要事先排好：在「③ 預約開始」填日期、時間、醫師姓名，按「預約」。要改時間請先「取消預約」再重新預約。
  3. 在記錄清單按「報表」，可以列印／存成 PDF，或下載 CSV。
