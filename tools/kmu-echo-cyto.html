高醫甲狀腺超音波病理查詢（Chrome 插件）

複選日期與時段，自動抓甲狀腺超音波名單，再逐位取得甲狀腺與頸部淋巴結細胞學的最近一次報告，整理成一張表，可下載 CSV。atypia、suspicious、malignant 整列上底色。

下載

插件 v1.1.0（zip） 只查病歷號：甲狀腺細胞學批次查詢

只在院內網路可用（高醫、岡山）。沿用你在 Chrome 已登入的院內連線，插件不處理帳號密碼；名單與報告只留在查詢頁，關掉分頁就清除，只記住院區、職編與科別代碼。

安裝（第一次）

  1. 下載 zip，解壓縮到一個固定的資料夾（之後不要搬動或刪除）。Windows 用「解壓縮全部」時會多包一層，請選到裡面有 manifest.json 的那一層。
  2. Chrome 網址列輸入 chrome://extensions，打開右上角「開發人員模式」。
  3. 按「載入未封裝項目」，選剛才的資料夾。
  4. 點右上角拼圖圖示，把「高醫甲狀腺超音波病理查詢」（綠底「超」字圖示）釘選到工具列。

更新到新版

  1. 新版解壓後，直接覆蓋原本的資料夾。
  2. 到 chrome://extensions，在這個插件上按「重新載入」↻。

使用

  1. 先在 Chrome 打開一次院內系統，確認已登入。
  2. 點插件圖示，會開出查詢頁。選院區，第一次使用要填職編；科別代碼預設 0160，可改。
  3. ① 選日期：起訖日期＋勾星期幾，按「加入日期」。不連續的日期可以分好幾次加入，最多 31 天；單一天就起訖選同一天。
  4. ② 勾時段：上午、下午、夜診，可複選。
  5. ③ 按「抓名單」：每個日期×時段各查一次，同一位病人只列一次，保留他所有的超音波日期時段。今天以前的日期抓「已執行」，未來的日期抓「已排檢未執行」。
  6. ④ 按「抓報告」：逐位查細胞學報告（超過 100 位要再按一次確認）。查完按「下載 CSV」。

分級上色（只看 Diagnosis 欄）

atypiaAtypia of undetermined significance／AUS／FLUS／Bethesda III／atypical cells
suspiciousSuspicious for malignancy，以及 cannot rule out／cannot be excluded 這類無法排除的寫法
malignantMalignant、carcinoma、cancer、metastatic、lymphoma、Bethesda VI（已排除「Negative for…」這類否定句）

Benign、Nondiagnostic、Follicular neoplasm（Bethesda IV）不上色。上色只是提示，不能取代逐份閱讀報告。

注意
  • 抓名單、抓報告時，插件會在背景開分頁、用完自動關掉，請不要去點它；查詢期間也不要在同一個 Chrome 另開別的病人病歷。
  • 防串號：報告與頁面上的病歷號都要對得上名單的號碼；對不上會標「查詢失敗：與查詢不符」且不輸出報告。標「請抽查」的，請對照電子病歷確認。
  • 院內連線過期、被導到登入頁時會整批停止，不會誤當成空名單或「沒有報告」。
  • 查詢中途關掉查詢頁，可能留下沒關掉的背景分頁，請手動關掉。
