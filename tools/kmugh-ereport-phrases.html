eReport 自訂快速片語（Chrome 插件）

在 KMUGH eReport 打報告時，旁邊叫出自己建立的片語，點一下就插入目前游標位置。片語可分組、搜尋、編輯；面板可以拖到不擋畫面的地方。

下載

插件 v1.2.1（zip） 內建片語（JSON，98 筆）

只在 ereportap.kmugh.org.tw 的報告頁面運作，需在院內網路使用。內建 98 筆常用片語（甲狀腺超音波、備註、ABI、眼底、診斷書、Sudoscan 9 種分級等），第一次安裝自動放入。JSON 檔是同一份片語，可用面板的「匯入」加入。片語只存在你這台電腦的 Chrome 裡，不會上傳；插件不會暫存或送出報告。

安裝（第一次）

  1. 下載 zip，解壓縮到一個固定的資料夾（之後不要搬動、改名或刪除）。zip 裡直接就是 manifest.json 等 5 個檔案，請先自己建一個資料夾再解壓進去。
  2. Chrome 網址列輸入 chrome://extensions，打開右上角「開發人員模式」。
  3. 按「載入未封裝項目」，選剛才的資料夾。
  4. 重新整理 eReport 報告頁面，右上角就會出現「eReport 自訂片語」面板。

更新到新版（片語不會不見）

  1. 新版解壓後，把 5 個檔案直接覆蓋（或放進）原本的資料夾。
  2. 到 chrome://extensions，在這個插件上按「重新載入」↻。
  3. 重新整理 eReport 頁面。
  4. 從 v1.1.0 更新的：原本的片語都還在，內建片語不會自動加入，請按面板上的「載入內建片語」。相同的片語不會重複。

請不要「移除」舊版再載入新資料夾。Chrome 是用資料夾位置認未封裝的插件，移除或換資料夾就會被當成另一個插件，原本建立的片語會讀不到。

使用

  1. 先點一下報告裡要輸入的欄位，面板上方會顯示「插入目標」。
  2. 在面板搜尋或切換分組頁簽，點片語就插入游標位置；多行片語插入大欄位時保留換行，插入單行欄位時換成空格。
  3. 「＋新增片語」建立片語與分組，可加選填「標題」（只顯示在清單、不會插入報告）；每筆片語旁可編輯或刪除。
  4. 「匯出」把目前全部片語下載成 JSON 備份；「匯入」從 JSON 檔加入片語（相同的不重複，不會刪掉現有片語）。換電腦時先匯出再匯入。
  5. 移動面板：按住深藍色標題列拖曳。放開後位置會記住，下次開頁面沿用。雙擊標題列回到右上角預設位置。
  6. 標題列右邊的 −／+ 可以縮小或展開面板。
